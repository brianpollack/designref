Anatomy

BoxOne bordered container that owns the focus ring, so the text area, the format row and the actions read as one control.
Text areaA textarea one line tall until text makes it grow, up to eight lines, then it scrolls inside the box. It holds plain text; formatting is markdown typed or inserted.
Formatting rowBold, italic, code and link. They wrap the selection in markdown markers. Slack, Google Chat and Discord all take typed markdown, and Slack lets the row be hidden.
Action rowAttach, emoji, mention on the left; a hint and the send button on the right.
Attachment chipsOne per file, above the text, each with a remove button.
Mention listOpens above the box when @ starts a word. People, with their role. It never takes focus from the box.
Emoji pickerA popover of emoji above the box, right aligned to it. Choosing one inserts it at the caret.
SendDisabled and faint while there is nothing to send; filled in the accent color when there is text or an attachment.

Specs

Behavior

SendEnter sends; Shift+Enter starts a new line, as in Slack and Teams. Slack offers a preference to swap them, and Teams uses Ctrl+Enter once the box is expanded. Never send while an input method is composing (isComposing).
Growfield-sizing: content with min-height: 1lh and max-height: 8lh. No resize observer and no script measuring text.
@ mentionOpen on @ at the start of a word, filter as the word grows, close when it stops matching or on Esc. Enter or Tab inserts the name and a space. Mentioning someone outside the channel should offer to add them, as Google Chat does.
Mention in a DMGoogle Chat treats a mention in a one-to-one chat as a reference only, because the other person is notified anyway.
MarkdownThe toolbar and typing both produce markdown. Discord documents **bold**, *italic*, ~~strike~~, ||spoiler|| and [text](url); Google Chat uses single-marker *bold* and _italic_. Pick one dialect and render it the same everywhere.
DraftsKeep what was typed when the user switches channel. Google Chat saves a draft after 5 seconds of paused typing, keeps up to 100 drafts, and drops them 30 days after the last edit.
AttachThe button opens the file picker; dropping files on the box and pasting images should do the same. Each file becomes a chip before the message is sent.
LimitsDiscord caps a message at 2,000 characters and shows no error until sending, so show a count as the limit nears and keep what was typed.
Edit last message↑ in an empty box edits your last message in Slack and Discord. In the channel demo, ↑ moves up through messages instead; choose one and document it.
DisabledIf posting is not allowed (a read-only channel, or a call where the host turned chat off), replace the box with a sentence saying so, rather than a disabled box with no reason. See Meeting Chat Panel.

Code

Accessibility

KeyDoes
EnterSend, or insert the highlighted person while the list is open.
Shift + EnterNew line.
↑ ↓Move through the mention list; the box keeps focus.
TabInsert the highlighted person while the list is open; otherwise move to the toolbar and actions.
EscClose the list or the emoji picker.
  • The mention list follows the APG combobox pattern: DOM focus stays on the input, aria-activedescendant names the highlighted option, and aria-expanded and aria-controls describe the list. APG documents the single-line case; this adapts it to a textarea, and that adaptation is ours, not APG’s.
  • Every icon-only button has a label, including the formatting row and the chip remove buttons.
  • The ring is on the whole box with a 1px border plus a 1px shadow, in both themes, so a focused box is clear without relying on color alone.
  • The send button is real disabled when there is nothing to send, so it leaves the Tab order and is announced as unavailable.
  • Slack returns focus to the box when an attachment is removed; the chip remove button here does the same.
