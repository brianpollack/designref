Anatomy

HeaderWho you are talking to: avatar with presence, name, one line of status.
Time stampA small centered line when the gap between messages is long, not on every message. The exact time of any message appears on hover.
Received bubbleLeft aligned, neutral fill, beside the sender’s avatar. The avatar shows only on the last bubble of a run.
Sent bubbleRight aligned in the accent color with white text. No avatar: the side is the sender.
Joined bubblesConsecutive messages from one sender stack with a 2px gap and a tightened corner on their side, so a run reads as one thought. A new sender opens a 10px gap.
Rich bubblesA link becomes a card inside the bubble. A message that is a single emoji drops the bubble and is shown at 40px. A reaction is a small badge overlapping the bubble’s top corner.
StatusOne line under your most recent message: Delivered, then Read with the time. Only the last, not every message.
TypingThree dots, outside the message list, so it is announced as a status and never becomes a message.
ComposerAttach, a pill that grows, emoji, and one trailing button that is the microphone while the box is empty and send once it is not.

Specs

Apple publishes no geometry for the Messages app’s bubbles, so these values are our own. Teams’ own values are on Fluent 2 Teams Chat.

Behavior

GroupingDone in CSS by reading the next row: .row.me:has(+ .row.me) tightens the lower corner, .row.me + .row.me tightens the upper one. Add or remove a message and the corners recompute with no script.
SendingEnter sends, Shift+Enter is a new line. The row is added optimistically and the status line changes to Delivered; replace it with Failed and a retry if the request fails.
Read receiptA separate, ephemeral signal from the other side, not part of the message. In Matrix it is an “up to here” marker; the status shows against the last message at or before it.
TypingSent while the user types and expired after a few seconds without a keystroke. Matrix clients send it with a timeout (30 seconds in the spec’s example) and replace their whole typing list on each update.
HoverOn hover or focus a row can reveal its time and actions beside the bubble. On touch, a long press opens the same actions.
Reduced motionThe typing dots hold still.

Accessibility

  • The list is role="log" with a name that says who the conversation is with. Each sent and received message is announced politely as it arrives.
  • Side and color are not the only signal of who spoke. Give each bubble an accessible name such as “Priya, 9:41 AM” or “You, 9:42 AM” (omitted here to keep the markup short), and keep the avatar decorative.
  • Typing is a role="status" region outside the log. Its text is visually hidden; the dots are decoration.
  • An emoji-only message needs a text name (“Party popper”), since screen readers vary in how they read a lone emoji.
  • White on the sent fill is at least 4.9:1 in both themes; received text is the full text color on a neutral fill.
  • The mic and send buttons are one position, so a keyboard user’s Tab stop does not move when the text changes.
