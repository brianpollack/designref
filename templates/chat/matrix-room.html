Anatomy

Room header64px tall with a 1px rule: room avatar, name and a one-line topic.
TileOne event. Element’s modern layout reserves a 64px gutter on the left: the avatar sits 8px in, and on hover a 46px slot shows the time at 10px. Text starts after the gutter, with 18px above a new sender and none above a continuation. Hover fills the tile with a subtle fill and an 8px corner.
NameDisplay name in weight 600 at the body size. Element adds the Matrix ID in a secondary color when two people share a display name.
Action barAbsolute, right 8px, resting just above the tile’s top edge: a canvas-colored bar with a 1px border and 8px corner, holding 28px icon buttons with 3px margin and a 6px corner.
ReactionsPills with 1px of vertical and 6px of horizontal padding, a 1px border and a 10px corner. Yours is green. The add button is 16px and appears with the tile’s hover.
Thread summaryA 40px bar with an 8px corner under the root message: the latest reply’s sender and text, and the reply count. A border appears on hover.
New-messages lineA 1px accent rule with a medium-weight accent label.
Read receiptsA right-aligned row of 14px avatars with a 1px canvas ring, under the last event they have seen.
ComposerA 1px hairline above, 60px minimum height, text at the body size growing to 120px; 20px icon buttons with 6px between.
Agent memberMindRoom agents are ordinary Matrix users, so an agent tile is a normal tile. The rounded-square avatar and the “Agent” badge are ours, to make a non-human sender clear at a glance.
Tool traceMindRoom shows tool calls as collapsible traces. A details with a one-line summary (count, time) and one line per call: the tool, its arguments, the result.
Approval cardMindRoom asks before sensitive actions and shows what will be sent and to whom. Two buttons; once chosen they are replaced by what was decided.
StreamingThe reply grows in place with a caret and a Stop button, as MindRoom’s agents “type into the room with progressive edits, visible tool traces, and cancellation”.

Specs

Color, type and spacing are Compound’s own tokens, read from its published CSS. Compound has no radius tokens; the 8, 10 and 6px corners are values Element hard-codes. Element computes the timeline avatar size in code, and we did not find it: the 30px here is our choice. MindRoom’s own UI measurements are not published.

What a message is in Matrix

ConceptOn the wire
Messagem.room.message with msgtype and a plain body; optionally format = org.matrix.custom.html and a formatted_body from a small tag set (headings, lists, links, code, tables, span with data-mx-spoiler).
Kindsm.text, m.emote (the /me line), m.notice (for automated senders: show it distinctly and never auto-reply to it), and m.image, m.file, m.audio, m.video whose body is the filename or a caption.
Replym.relates_to.m.in_reply_to.event_id. No rel_type.
Threadrel_type: m.thread pointing at the root. Every event in the thread references the root; threads cannot nest.
Editrel_type: m.replace with m.new_content. Same sender, room and type; an edit cannot be edited. This is how a streaming reply grows: many edits of one event.
ReactionAn m.reaction event with rel_type: m.annotation and a key that is the emoji.
Read receiptA marker saying “I have read up to here”, per user, with m.read, m.read.private or m.fully_read. A receipt can be scoped to a thread, or to main.
TypingEphemeral. A client sends typing: true with a timeout; each update replaces the whole list of who is typing.

Behavior

Agent repliesMindRoom replies in threads using Matrix thread relations. In a thread with one human, the agent keeps answering without being tagged; once two or more humans are in it, agents answer only when tagged. If nobody is tagged a router picks one.
StreamingEach update is an edit of the same event, so the timeline shows one message that grows, not many. A Synapse fork exists “for faster message edit streaming”. Stop sends no more edits and leaves what was written.
ApprovalThe agent blocks on the card. The decision replaces the buttons so the record shows who decided what.
TimestampsShown in the gutter on hover or focus, so a quiet timeline has no clock noise.
LayoutsElement ships three: modern (this one), IRC (a dense single line with a fixed-width name) and bubble (12px corners, 70% max width, others gray and yours green).
MindRoom’s own viewsIts client has a Compact thread view (one card per thread with status and sort filters) and a Threads view (a badge under each thread’s first message). Agents title threads; users can rename, tag, pin or resolve them.
Reduced motionThe streaming caret stops blinking.

Code

Accessibility

  • The timeline is role="log" with a name. Each tile is focusable and summarised by an aria-label of sender and time; Tab then reaches its action bar, reactions, links and trace.
  • The streaming reply should not be re-announced on every edit: keep it out of the live announcement until it finishes (for example aria-busy on the tile while it grows), then announce once.
  • The tool trace is a native details and summary, so it is keyboard operable and its state is exposed with no script.
  • The approval card is a labelled group. It is not a modal: the room stays readable while the decision waits. Do not auto-focus its buttons.
  • The agent badge is text, not only the avatar shape or color.
  • Compound’s secondary text is #656d77 on white (5.2:1) in light and #808994 on #101317 (5.3:1) in dark. The 10px timestamp is Element’s own choice and is small; keep it for a hover aid and do not use it for anything a reader needs.
