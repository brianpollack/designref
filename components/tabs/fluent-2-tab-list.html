Anatomy

Tab listA flex row with no gap. Each tab’s own padding makes the space between labels. Horizontal by default; vertical stacks it.
TabA button with role="tab": an icon (optional) and a label, 4px corners. Sizes: small 6px × 6px padding, medium 12px × 10px (default), large 16px × 10px.
Labelbody1, 14 / 20 at weight 400; selected, body1Strong at 600. Large tabs use body2 (16) and subtitle2. Space for the bold weight is reserved so selection never shifts the row.
Icon20px (large 24px). Regular at rest, Filled when selected, in the brand color.
Selected indicatorA pill, 3px tall (small 2px), brand color, inset 12px from each side of the tab so it is narrower than the tab. One indicator slides between tabs.
Pending indicatorThe same pill in a neutral stroke color, under an unselected tab on hover and press: a preview of where selection would go.
Appearancetransparent (shown), subtle (fills on hover) and the circular appearances, which swap the indicator for a rounded fill. Only transparent is built here.

Specs

Behavior

SelectingClick, or arrow to a tab: selection follows focus.
IndicatorSlides over 300ms (durationSlow) on curveDecelerateMax. Fluent animates the indicator’s transform; this page animates its anchored insets, with the same duration and curve. Reduced motion jumps it.
HoverText and icon darken one step. An unselected tab also shows the pending indicator; the selected indicator darkens to the hover brand color. The tab itself never fills in the transparent appearance.
PressOne step darker again, on the same colors.
DisabledThe label and icon use the disabled foreground, no hover and no pending indicator. Arrow keys skip it.
FocusA 2px ring in colorStrokeFocus2 around the whole tab plus shadow4, so it does not collide with the indicator. A transparent outline keeps it visible in forced-colors mode.
