Core libraries

The modern stack

Tabs need less script than they used to. Most of what is left is the part the platform still cannot do.

  • Anchor positioning places one indicator against the selected tab. Name the selected tab as the anchor and the indicator’s left and right follow it; a transition on those two properties makes it slide. No measuring, no ResizeObserver.
  • scroll-target-group and :target-current turn a row of in-page links into scroll-spy tabs with no script at all.
  • :has() lets the row react to the state of one tab, such as darkening the shared indicator while the selected tab is hovered.
  • light-dark() keeps both themes in one set of tokens.

What still needs script: arrow keys, Home and End, and the roving tabindex and aria-selected that make a tablist a tablist. focusgroup="tablist" is meant to cover the keys but did nothing in Chrome 156, so each page carries a short keydown handler.

If the tabs are links to other pages, they are navigation, not a tablist: use links with aria-current="page" and none of this script.
