Anatomy

Tab listOne row of buttons with a 1px rule beneath. Labels sit side by side with a 4px gap; the row never wraps.
TabA button with role="tab", 40px tall, 14px / 20px at weight 500. Only the color changes with state, so selecting never shifts the layout.
IndicatorA single 2px bar that spans the selected tab and slides to the next. It is the row’s ::after, positioned against the selected tab by anchor name.
PanelA role="tabpanel" with tabindex="0" so a keyboard user can reach content that has nothing focusable in it. Hidden panels use hidden.
LabelsOne or two words, sentence case. If a label needs a count, put it in the label text rather than a badge.

Specs

Behavior

SelectingClick, or arrow to a tab: focus and selection move together, because the panels are already on the page.
IndicatorSlides over 250ms. Its edges come from anchor(left) and anchor(right) of the tab named --tb-active; moving that name is the only thing script does for it.
Tab stopThe selected tab is the only one in the Tab order. Tab enters the row at the selected tab and leaves it for the panel.
HoverA soft fill and the selected text color. It never shows the indicator: that means selected.
Reduced motionThe indicator jumps to the new tab.
Use forSwitching between views of one thing. If the tabs are the site’s navigation, use links and aria-current instead; see Scroll-Spy Tabs for sections of one page.

Accessibility

KeyDoes
TabMove into the row at the selected tab, then out to the panel.
← →Previous and next tab, wrapping at the ends, selecting as it goes.
Home EndFirst and last tab.
  • Chrome does not yet honor focusgroup="tablist", so a short keydown handler supplies the arrow keys, wrapping, Home and End. Move to focusgroup when it ships.
  • Each tab names its panel with aria-controls and each panel names its tab with aria-labelledby.
  • Focus ring: 2px in the accent color, inside the tab. Selected state is shown by aria-selected, the darker text and the indicator, never by color alone.
  • If switching tabs has to load data, use manual activation (arrows move focus, Enter or Space selects) so each arrow press does not fire a request.
