Anatomy

BarA sticky strip holding a nav of in-page links, with a 1px rule under it. It stays at the top while the sections scroll beneath.
TabAn ordinary a href="#section", 40px tall, 14px / 20px at weight 500. These are links, not role="tab": nothing is hidden, the page just scrolls.
Scroll markerscroll-target-group: auto on the nav turns each link into a marker for its target section. The browser tracks which one is in view.
Current tabThe link matching :target-current: darker text, and it holds the anchor name the indicator follows.
IndicatorOne 2px bar, the nav’s ::after, spanning the current tab and sliding as the section changes.
SectionsEach has the id its tab links to. Make the last one tall enough to scroll to the top, or its tab can never become current.

Specs

Behavior

ScrollingThe current tab changes as sections cross the top of the viewport. The browser decides which one is current; there is no scroll listener and no script on this page.
ClickingA normal anchor jump, smoothed with scroll-behavior. scroll-padding-top keeps the section heading clear of the sticky bar.
Direct linksOpening the page at #usage lands on that section with its tab already current.
IndicatorSlides over 250ms, the same anchor technique as Underline Tabs. Reduced motion removes the slide and the smooth scroll.
Use forLong pages split into a few named sections. For separate views that replace each other, use Underline Tabs.

Accessibility

KeyDoes
TabMove through the links like any others. They are all in the Tab order; this is not a single-stop tablist.
EnterScroll to the section. Focus stays on the link.
  • Links in a labeled nav are the right semantics here: a tablist would promise hidden panels and arrow keys this does not have.
  • :target-current changes how the link looks, not what assistive technology is told. If the current section matters to a screen reader user, the headings and landmarks already carry it.
  • Current state is shown by darker text and the indicator, not color alone.
  • Focus ring: 2px in the accent color, inside the link.
