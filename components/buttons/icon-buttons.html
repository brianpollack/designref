Anatomy

Hit area44px square, the real button. The visible face is a 40px circle drawn by ::before, 2px inside, so a small-looking control still has the target Apple and WCAG’s enhanced level ask for.
Icon24px, in the text color. A familiar symbol for a familiar action (Apple: plus to add, trash to delete, xmark to close, ellipsis for more, share, magnifying glass to search). Apple prefers system symbols without borders in toolbars.
StandardNo face until hover. For toolbars and dense rows.
FilledAccent face. The one icon button that matters.
TonalSoft face. A secondary icon action.
Outlined1px border. A quiet but contained icon action.
ToggleAn icon button with aria-pressed. On, the icon takes the accent color on a tinted face; the accessible name stays the same.
TooltipA popover="hint" linked by interestfor: it shows on hover or keyboard focus and names the action in words.
FABA raised accent button for the one main action on a screen. Small 40px (12px corner), regular 56px (16px), large 96px (28px, 36px icon): Material 3’s sizes.
Extended FABFAB with a label. 56px high, 16px side padding, 8px between icon and label. Its label folds away as the list scrolls.

Specs

Sizes follow Material 3’s icon-button and FAB tokens (small icon button 40px with a 24px icon; FAB 40, 56, 96px; extended FAB 56px high). Colors and the elevation shadows are ours: Material’s rest and hover levels are 6dp and 8dp, approximated here.

Behavior

NameEvery icon button has an accessible name (aria-label) and, on hover or focus, a visible one. Apple: provide alternative text for custom icons. A tooltip is not the name; it repeats it for sighted users.
Tooltipsinterestfor works on a button and fires interest and loseinterest; Esc dismisses. Support is recent: Chrome 149 and later per caniuse, while an earlier intent-to-ship targeted 142, so the version is unresolved; feature-detect with Object.hasOwn(HTMLButtonElement.prototype, "interestForElement").
ToggleOne name, aria-pressed for state, a tinted face and accent icon for on. APG: the label of a toggle does not change when its state changes.
FAB useOne per screen, for the primary action, in the same place on every screen of that kind. If a screen has no single main action it should not have a FAB.
Extended FAB foldanimation-timeline: scroll(nearest block) with animation-range: 0 80px animates the label column from 1fr to 0fr and the gap to 0. It follows the scroll position exactly, forwards and back. MDN lists the property as newly available in 2026.
ElevationResting shadow rises on hover and returns on press.
Reduced motionTransitions stop and the extended FAB keeps its label.
Forced colorsFaces and FABs get a ButtonText border.

Code

Accessibility

  • Every button is 44px square or larger, over WCAG 2.2’s 24px and equal to its 44px enhanced level.
  • The extended FAB’s name is its label text; when the label folds away it is hidden only visually (zero-width, clipped), so the name remains in the accessibility tree.
  • Plain FABs and icon buttons use aria-label only because there is no visible text.
  • Toggle state is shown by aria-pressed and by a tinted face plus the accent icon. That is still color, so give a real product a shape change too (an outline star becomes a solid one).
  • Standard icon color is 8.9:1 on white; the outlined border is 2.2:1, so the icon, not the border, identifies the control.
