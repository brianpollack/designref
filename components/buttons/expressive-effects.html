Gradient borderA transparent border with two background layers: a solid fill clipped to padding-box over a conic-gradient() on border-box. The angle is a custom property registered with @property as <angle> so keyframes can animate it. conic-gradient() is an image, so it cannot set a color, and border-image would ignore the radius.@property: Baseline 2024, since Jul 2024. conic-gradient(): widely available since Nov 2020.
Spring presslinear() interpolates between many points and allows values past 1, which is the overshoot. Points here were computed from a damped cosine; Jake Archibald’s generator, linked on that page, makes others.Widely available since Dec 2023.
ShimmerA ::before band behind the label, moved on hover inside @media (hover: hover) and on :focus-visible. MDN: the feature describes the primary input only, so a hybrid device may report either.hover media feature: widely available since Dec 2018.
GlassA translucent fill and backdrop-filter. It only blurs up to the nearest backdrop root, so a parent with opacity below 1, filter, mask or clip-path flattens it. The fill stays 60–70% opaque to hold label contrast; @supports swaps in a solid fill.Baseline 2024, since Sep 2024.
Corner shapecorner-shape needs a non-zero border-radius. squircle is superellipse(2), scoop is -1 (concave), notch is -infinity. Chrome’s own write-up, The corner cases of implementing CSS corner-shape in Blink, says it shipped in 2025.MDN: limited availability, not Baseline. Chrome blog: shipped 2025; no version number given.
KeycapLayered box-shadow: an inset highlight, a hard shadow for the side, a soft one for the desk. Pressing moves the key down by the side’s depth and collapses the side shadow. Forced colors removes box-shadow, so the page adds a border there (MDN’s own fix).forced-colors: widely available since Sep 2022.
Gradient textbackground-clip: text with color: transparent. MDN asks for a contrast check, a fallback color and an @supports not alternative; all three are here.background-clip: widely available since Jul 2015. The text value was not listed separately.
color-mix() laddercolor-mix(in oklab, base, shade N%) derives hover and pressed from one base. The border uses a relative color, oklch(from base calc(l - 0.12) c h). The shade is light-dark(), so pressed gets darker in light and lighter in dark.color-mix(): widely available since May 2023. Relative colors: no Baseline or version on the page.

Specs

Behavior

PressedAll eight have an :active state: a 3% shrink, a deeper fill, or the key travelling down. It starts on pointer down, so the button answers before release.
Reduced motionThe gradient stops turning, the spring and the shimmer are removed, and transitions are off. Hover and pressed still change color.
Forced colorsEvery button gets a 2px ButtonText border and a Highlight focus ring. MDN: gradients and shadows are removed there, and color maps to the system color, so gradient-text labels stay readable.
Label contrastEach label is checked against its own fill at 4.5:1 or better in both themes, not against the effect. The shimmer band sits behind the label and is faint; the glass fill is mostly opaque.
Corner shapeChrome draws each shape from the same border-radius. Because it is a CSS property, there is no script and no fallback: a browser without it shows plain rounded corners.
Use forOne call to action, not a whole toolbar. Effects compete: pick one per view.

Accessibility

KeyDoes
TabMoves to each button. The shimmer plays on focus, as on hover.
Enter SpaceActivate. These are native buttons; nothing is rebuilt.
  • Focus ring: 2px, 3px off the edge, in --fx-focus. On glass it takes the label color so it reads over the art.
  • WCAG 1.4.3 asks for 4.5:1 on text, 3:1 for large text. Gradient text uses stops at 6:1 or better on the surface because the contrast changes along the word.
  • Targets are 44px tall, above the 24px minimum (2.5.8) and at the enhanced size (2.5.5, AAA).
  • Motion that is purely decorative is removed under prefers-reduced-motion; the press itself is a state change and stays.
