Anatomy

ElementA button, or with asChild any element, usually an a. It carries data-slot="button", data-variant and data-size, so parents (a button group, a form) can style it without knowing its classes.
Boxinline-flex, centered, 1px border that is transparent except on outline, rounded-lg (10px), bg-clip-padding so a translucent fill stops inside the border.
Labeltext-sm (14px, 20px line height), font-medium (500), never wraps. The small size uses 12.8px and extra small 12px.
IconAny svg child is 16px (14px at sm, 12px at xs) unless it has its own size-* class, and ignores the pointer. data-icon="inline-start" or "inline-end" trims the padding on that side.
SizesHeight xs 24px, sm 28px, default 32px, lg 36px; side padding 8px at xs, 10px otherwise. Icon-only sizes are squares of the same heights.
VariantsDefault (solid primary), outline (border, page fill), secondary (gray fill), ghost (no fill until hover), destructive (red label on a 10% red tint), link (underline on hover).
StatesHover changes the fill, pressed nudges the button down 1px, focus draws a ring, disabled is 50% opacity with no pointer events, and aria-invalid turns the border and ring red.

Specs

Colors are shadcn’s default neutral theme. Sizes and spacing are Tailwind’s scale (1 unit = 4px), written in the classes rather than as tokens.

Behavior

Variant and sizePick one of each. In React, <Button variant="outline" size="sm">; here, the classes that call produces. Extra classes win over the variant’s (tailwind-merge drops the one they replace), which is how rounded-full makes a round button.
HoverDefault fades to 80%; secondary mixes 5% of the text color into its fill; outline and ghost fill with muted; destructive deepens its tint. 150ms, Tailwind’s default transition-all.
PressedMoves down 1px, except a button with aria-haspopup, which opens a menu instead.
Focus:focus-visible only: the border takes the ring color and a 3px ring at 50% surrounds it (red on destructive). The ring is a box shadow, so it follows the corner radius.
Disabled and loadingNative disabled: 50% opacity and no pointer events. For loading, shadcn disables the button and puts a spinner first; the spinner is role="status" with the label “Loading”.
Invalidaria-invalid="true" gives a red border and ring. It is for buttons that act as a form field, such as a date picker trigger.
CursorTailwind v4 resets buttons to the default arrow cursor. shadcn suggests a base rule for cursor: pointer if you want it; this page keeps Tailwind’s default.
Dark modeThe tokens switch with light-dark(), and the dark: classes follow a dark class on <html> (shadcn’s convention). In dark, outline uses the input color for its border and fill, and destructive and ghost use stronger tints.

Accessibility

KeyDoes
Enter SpaceActivate. The link styled as a button responds to Enter only, like any link.
TabMove to the next button. Disabled buttons are skipped.
  • Icon-only buttons need an aria-label; shadcn’s own examples set one.
  • The destructive label is 4.0:1 against its tint in light (5.3:1 in dark), below the 4.5:1 WCAG asks for at this text size. Every other variant is above 14:1. To fix it, darken --destructive’s light value, for example to oklch(0.5 0.21 27).
  • The extra small size is 24px high, exactly WCAG 2.2’s minimum target. Use sm or larger for touch.
  • The default theme is grayscale, so primary and secondary differ by fill only, not hue. Add a brand color to --primary to make the main action stand out more.
  • The spinner’s animate-spin keeps turning under reduced motion. Use motion-safe:animate-spin if that matters for your product.
  • shadcn adds no type; inside a form a button submits by default. This page sets type="button".
