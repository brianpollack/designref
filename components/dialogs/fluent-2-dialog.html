Anatomy

TitleMandatory. Sentence case, no end punctuation unless it is a question. Named by aria-labelledby.
CloseTop right, only when the footer has no Cancel button.
ContentScrolls inside the dialog when it is taller than the viewport.
FooterUp to three actions. Primary first; buttons are end-aligned with an 8px gap and stack below 480px.
Bottom padding24px. With no footer, the dialog adds 24px below the content.

Specs

Footer count, the 8px gap, the 24px padding and the 480px stacking come from Fluent’s dialog guidance and footer styles. The colors, widths and corners are ours; this page does not claim Fluent’s tokens.

Behavior

DismissalFor modal dialogs: an area outside the container, Escape, or a footer button. Fluent asks for a Close button top right only when there is no Cancel.
Alert dialogsUse an alert dialog for potential loss, such as unsaved changes or a destructive confirmation. It can only be dismissed by a footer button, so Escape and an outside click do nothing: see Destructive Confirm.
FocusOn open, the first interactive element in the dialog receives focus. On close, focus returns to the element that opened it.
NestingFluent says not to nest dialogs. Open the second one from a footer action instead.
Motion180ms fade and an 8px rise on enter and exit. Reduced motion removes it.

Accessibility

KeyDoes

EscCloses a modal dialog with no value.
  • The dialog title is the accessible name; the Close button has a label because it is an icon.
