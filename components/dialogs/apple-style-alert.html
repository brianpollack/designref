Anatomy

AlertA centred group with a short title, one line of message and two actions side by side with a hairline between.
Action sheetA bottom list of choices, with Cancel in its own group at the bottom.
DestructiveOne action in the destructive color (red), labelled with its verb. It is not the default action the user is most likely to choose.
Hit area44pt tall actions, the HIG’s hit region on iOS. Rules check measures it.

Specs

Inspired by Apple’s alert and action sheet. Apple publishes no radii or type sizes for these, so the corner radius, widths, blur and the blue and red are ours, matched to what iOS shows. The light-mode blue is darker than Apple’s #007AFF, which measures about 4:1 on white and fails WCAG’s 4.5:1 for text. Hit areas follow the HIG.

Behavior

When to use an alertCritical information the user needs right away, usually about a problem or a change, per the HIG’s alerts guidance.
When to use an action sheetChoices tied to an action the user started. HIG: Cancel is required, and it is best to keep the other choices to about three.
DismissalCancel, Escape, or a tap outside. An alert whose action has to be taken can drop the outside tap; this demo keeps it.
MotionThe alert scales up 6% over 260ms; the sheet slides up 24px. Reduced motion removes both.
