Anatomy

ContainerA <dialog> opened with showModal(). The browser puts it in the top layer, so no z-index or stacking context of the page can cover it.
TitleA visible heading named by aria-labelledby. Fluent requires one; the APG requires a name for every dialog.
BodyOne sentence of consequence or context, named by aria-describedby.
ActionsTwo buttons in a footer, aligned to the end. The primary is the one the user most likely wants; the cancel is quieter.
BackdropThe ::backdrop pseudo-element, a scrim over the page. Clicks on it close the dialog with closedby="any".

Specs

These are ours. The container radius, padding and the 420px width are a neutral default, not a system's value; the Material, Fluent and Carbon pages carry their own.

Behavior

OpenshowModal(). A non-modal show() dialog has no backdrop and no inert page, so closedby does nothing there.
CloseEscape, a backdrop click (closedby="any"), or a method="dialog" form button. Each sets returnValue to the button’s value; Escape and backdrop leave it empty.
FocusOn open, the first focusable element inside receives focus. On close, focus returns to the element that opened the dialog, unless it no longer exists.
Page behindInert while open: clicks and Tab do not reach it. Chrome’s closedby guidance is that a click starting inside the dialog and ending on the backdrop should not close it; the fallback checks the press position.
Motion200ms opacity and an 8px rise on enter and exit; the scrim fades. Reduced motion removes all of it. Exit uses allow-discrete so the dialog stays on screen until the fade ends.
Empty and longA long body scrolls inside the dialog, not behind it: keep the title and actions visible.

Accessibility

KeyDoes
Tab Shift+TabMove through the dialog; focus does not leave it.
EscClose the dialog and return focus to the trigger.
EnterSubmits the form with the focused button’s value.
  • showModal() sets aria-modal="true" implicitly. The APG asks for a modal only when the page behind is really inert, and the browser makes it so.
  • The APG’s close guidance: include a visible button that closes the dialog. The Cancel button here does that.
  • Escape closes only the last modal shown when several are open.
