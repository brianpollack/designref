How it closes

QuestionWhat the platform gives
Can Escape close it?Yes by default on showModal(). closedby="none" turns that off, and closedby="closerequest" keeps only Escape and the platform’s back gesture.
Can an outside click close it?Only with closedby="any". Chrome: a press that starts and ends on the backdrop, not a drag that ends there.
Does it need a close button?The APG asks for a visible close control in every modal. Fluent places it top right when there is no Cancel.
Where does focus go?In on open, to the first focusable element. Back to the opening element on close. For a destructive final step, the least destructive action may take focus (APG).

Core libraries

The modern stack

A modal needs no library. These platform features replace what used to be a focus trap, a backdrop listener and a stacking rule.

  • <dialog> and showModal() put the dialog in the top layer, make the page behind it inert, and draw the ::backdrop. No z-index, no focus trap written by hand.
  • closedby gives Escape and the outside click declaratively. A script fallback covers browsers without it.
  • method="dialog" and returnValue return the chosen button’s value on close, so the page reads the result without a click handler.
  • Invoker commands (commandfor with show-modal and close) open and close a dialog with no script.
  • @starting-style and transition-behavior: allow-discrete animate the dialog and its backdrop in and out, including display.
  • container queries and media queries let one element be a sheet on a phone and a modal on a wide screen.

What still needs script: a value to return from a confirm before it closes, drag-to-dismiss on a sheet, and any focus trap for a custom element instead of a <dialog>. Each page carries a Rules check where a system applies.
