Anatomy

InvokerA button with commandfor naming the dialog and command="show-modal". The browser performs the action; there is no click handler.
Close invokerA button with command="close" on the same dialog. Used for Cancel, which returns no value.
Formmethod="dialog". Submitting closes the dialog and sets returnValue to the submit button’s value.

Specs

Values are ours, the same neutral defaults as Native Dialog.

Behavior

When to useA dialog that opens from one place and closes with one of its own buttons. Use the native dialog with a script when the open state must be set in code, or when you need the result before closing.
Opencommand="show-modal" opens the dialog modally. Focus goes to its first focusable element, as with showModal().
CloseEscape, a backdrop click (from closedby="any"), the Cancel invoker, or a submit. Only the submit sets a return value.
FocusReturned to the invoker that opened the dialog, when the invoker still exists.
